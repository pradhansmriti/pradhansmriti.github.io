## Doctoral research · Hepatitis B virus assembly

I study how protein interactions shape viral assembly and how drug binding changes the process.

- Developed coarse-grained elastic network models using OpenMM and NAMD, learning model parameters from all-atom simulation data.
- Used high-performance computing and weighted ensemble methods to explore rare assembly events.
- Extended a C++ kinetic Monte Carlo framework to model the effects of drug binding.
- Built Markov State Models to analyze assembly pathways and kinetics.
- Produced computational results that complemented in vitro experiments.

[Elastic network modeling](/projects/hbv-elastic-network/) · [Kinetic Monte Carlo simulations](/projects/hbv-monte-carlo/)

## Selected software and machine learning projects

### AgenticVMD

Built a natural language interface that generates editable VMD Tcl scripts for molecular visualization. The project connects an LLM tool-use API to a scientific workflow, letting users move from a description to a rendered molecular structure.

[Project and code →](/projects/agentic-vmd/)

### Binding affinity prediction

Built a pipeline to predict protein–ligand binding affinity from structural features and molecular fingerprints. Compared tree-based and neural models, used a sequence-identity split to address data leakage, and analyzed feature contributions with SHAP.

[Methods and results →](/projects/binding-affinity-ml/)
